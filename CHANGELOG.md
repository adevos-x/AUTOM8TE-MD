# Changelog

All notable changes to AUTOM8TE MD are listed here, newest first.
Send `.update` to your bot to get the latest version.

Format: **Added** new things, **Changed** things that work differently, **Fixed** things that were broken.

## [1.0.7] - 2026-10-31

### Fixed 
- Some common issues


### Added
- Antigroupstatus cmd

## [1.0.6] - 2026-10-29

### Fixed 
- sticker commands
- play command
- post groupstatus 


## [1.0.2] - 2026-10-24

### Added
- Support for video and GIF tools (ffmpeg).

### Fixed
- `.toimg` (sticker to image) works without any extra program.
- The menu showed an old version number after an update.

## [1.0.1] - 2026-10-23

### Fixed
- Many commands that use online services now try backup providers automatically, so they fail less often.

## [1.0.0] - 2026-10-21

### Added
- First release of AUTOM8TE MD: a WhatsApp Multi Device bot with 450+ commands.
- Connect and deploy from the website with a pair code or a QR code.
- `.update` and `.restart` commands.
- The bot reports its version, so updates can be rolled out safely.
